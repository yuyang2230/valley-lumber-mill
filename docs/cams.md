# 山谷·伐木场 —— QA 机位表（cams.md）

配套文档：`docs/ANALYSIS-valley.md` §8.1（URL 参数）。

## 使用方式

机位通过启动参数 `?cam=x,y,z,lx,ly,lz` 生效（`index.html:6562` 行 `window.__setShot`：前三个数是相机位置，后三个是注视点；**后三个省略时默认 look=(0,1,0)**，`cam=` 空串可清除）。机位在每帧 `render.frame` 之前硬覆写相机，`?autostart=1` 开局、`?shot` 进入拍照模式（画质锁 test 档、关动态分辨率）。完整示例：

```
index.html?autostart=1&cam=-14,1.7,-19.5,10,4,-19.5&fov=74&exposure=1
```

## 坐标系约定（本表的前提）

新布局沿用现世界框架（便于直接套用现引擎常量，改版时无需换算）：
- 地面 `groundY=0`，世界边界 `oi={min(-40,0,-30), max(40,30,30)}`（`index.html:4184`）；
- 分区沿用 zones 四象限改语义：`gate(西, x<-24)`→**河谷/瀑布**、`yard(北, z>-10)`→**原木堆区**、`shed(南, -28≤z≤-11, -16≤x≤12)`→**中央大仓库**、`quay(东, x>16)`→**板材区/公路**；
- 站立眼高 `Pi.eye=1.68`（`index.html:4186`），故地面机位统一 `y≈1.7`。
- 若 remake 平移了布局，请按新 zones 同步平移本表（机制不变）。

## 5 个 QA 机位

### 1. 中央大仓库（主锯车间内部）
- **cam = `-14,1.7,-19.5`**  **look = `10,4,-19.5`**
- 位置说明：站在仓库西门内，沿主通道向东看锯切线；注视点抬高 4m 是为了同时框住 `no.RIDGE=9.5` 天窗带（`index.html:5557` `no={X0:-16,X1:12,Z0:-28,Z1:-11,EAVE:7,RIDGE:9.5,…}`）与地面设备。
- 覆盖 `interiorBoxes[0]` 内部（x -16..12, z -28..-11）——此机位必查：室内 PMREM 探针（render.K）、体积光尘埃 `uBoxDust`、室内雨声切换、武器湿润度判定（QC 主循环取 `interiorBoxes[0]`）。

```
index.html?autostart=1&cam=-14,1.7,-19.5,10,4,-19.5
```

### 2. 原木堆区（yard 北段露天垛场）
- **cam = `-4,1.7,26`**  **look = `12,2,18`**
- 位置说明：从北缘向东南看 2~3 组原木长垛（建议垛区落位 x 0..14, z 14..28，对应旧 yard zone `min:[-24,-10],max:[16,30]` 北半部）。
- 必查：wood 材质 triplanar 在大垛上的平铺感、垛体 `userData.colliders` 注册后 nav 封锁（原木垛应 `noNav` 或按层）、coverPoints 吸附是否落在垛间通道。

```
index.html?autostart=1&cam=-4,1.7,26,12,2,18
```

### 3. 板材区（yard 南段成材晾晒场）
- **cam = `-18,2.0,2`**  **look = `-2,1.5,10`**
- 位置说明：西高视角俯向板材架列（建议落位 x -14..4, z 2..14，对应旧 yard zone 西南角与旧 coverPoints 群 `(-12,0,-25)…(6,0,-14)` 的开阔面）。
- 必查：分层板材架（类似旧 `shelf_rack`/`pallet_stack`，尺寸表 `Gi` 5539 行）的阴影自遮挡、Hound 在窄巷用 coverPoints 选位的通视性、AO 在板材夹缝的收敛。

```
index.html?autostart=1&cam=-18,2,2,-2,1.5,10
```

### 4. 河谷瀑布（西端 gate→河谷）
- **cam = `-25,3.2,2`**  **look = `-36.5,3.4,13`**
- 位置说明：站在河谷东岸小径南段向西北看——瀑布落水口（≈(-36,3,13)）居画面中偏右，左侧留出河谷水面与对岸开阔带；旧机位 `-27,2.4,10` 贴崖过近、视线被崖体侧壁占满，已后撤南移。（河谷水面沿用 `groundSurfaceAt` 的 `"water"` 语义但以 `oi.quayX` 改造为西侧河界，见 ANALYSIS §2.1。）
- 必查：瀑布水幕/落水粒子/水雾与天空 PMREM 的衔接（`en.fog` 空气透视）、彩虹光斑减淡闪烁、水面 raycast 返回 `surface:"water"` 触发的脚步/落水声、`physics.raycast` 地面双平面分支（x≤quayX 用 groundY 的逻辑要跟河界对调后仍成立）、远处雪山 backdrop 分支入画。

```
index.html?autostart=1&cam=-25,3.2,2,-36.5,3.4,13
```

### 5. 公路撤离点（东侧运材公路停车场）
- **cam = `24,1.8,-29`**  **look = `29,1,-22`**
- 位置说明：站在运材卡车侧后向撤离点看（撤离点建议沿用旧值 `extraction={pos:(29,0,-24), radius:2.5}`，6562→5703 行，东端旧 quay 区）。
- 必查：撤离触发半径 2.5m 与卡车模型的遮挡关系、`?bench` 运镜（cinematicPath 末段应路过此点）、全断中继后 `setMarkers` 的 EX 钻石标在此机位的可读性、追猎波次（pursuit）从公路方向刷出的 spawn 点选择（Q() 打分要求 spawnFar=18）。

```
index.html?autostart=1&cam=24,1.8,-29,29,1,-22
```
