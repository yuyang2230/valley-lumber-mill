# 《盐线：山谷·伐木场》

**单文件浏览器 FPS** —— 整个游戏只有一个 `index.html`：渲染引擎、场景、材质、音效、语音全部内嵌，无需安装、无需联网、无任何外部素材下载，双击即玩。

## 游戏简介

敌军重兵把山谷·伐木场围成了铁桶，4 人猛攻小队被困林中。你将扮演**突击位·芝士莓莓仔**，与三名会开麦的 AI 队友并肩作战——

| 角色 | 定位 | 说明 |
| --- | --- | --- |
| **芝士莓莓仔**（玩家操控） | 猛攻小队·突击位 | 沉稳果敢，"跟我上，别回头" |
| **抖音大棉花**（AI 队友） | 指挥 / 突击 | 梗王老哥，嗓门大、爱玩梗 |
| **小小薇**（AI 队友） | 狙击 / 战术 | 冷静话少，高地已就位 |
| **内果果果**（AI 队友） | 医疗 / 后勤 | 呆萌软糯，"果果在呢，别怕" |

**任务主题只有一条：4 个人毫发无伤，从伐木场重围中撤出。** 先切掉敌人 3 套电子压制节点撕开封锁，再跟着队友一路顶到河谷公路撤离点；有人倒下就扶起，一个都不能少。

## 本地运行

- **最简单**：双击 `index.html`，用现代浏览器（Chrome / Edge / Firefox）打开，点击开始即可。
- **本地服务器（可选）**：

  ```bash
  python -m http.server 8000
  # 浏览器访问 http://localhost:8000/index.html
  ```

- 进入标题画面后点击"开始"，浏览器可能会询问鼠标锁定权限，点击画面确认即可。
- 建议使用桌面端 Chrome/Edge 获得完整键鼠体验；移动端有专属触屏按键（方向键转向、换弹/跳跃屏幕按键）。

## 技术亮点

- **全程序化生成**：地形、建筑（原木堆、板材区、中央大仓库等）、树木、材质与贴图全部由代码实时生成，零外部资源，保持单文件零下载架构。
- **3 名可跟随 AI 队友**：基于 A* 寻路（nav.findPath）+ 串点跟随，失败直线兜底、卡住侧移脱困；队友会跟随、掩护、掉血、倒地，可被玩家扶起。
- **speechSynthesis 中文分队语音**：按"角色 × 事件"的全中文无线电台词表，四名队员各配独立声线参数（音调 / 语速区分男女声线），同步字幕显示。
- **软阴影 + AgX 后期管线**：PCFSoft 软阴影，后期链含自动曝光、环境光遮蔽、体积雾、泛光、镜头暗角 / 噪点 / 色散，AgX 色调映射混合，呈现电影化晨雾伐木场。
- **WebAudio 合成音效**：全部枪声、环境声由 AudioContext 程序化合成，无任何采样音频文件。
- **"毫发无伤"三档结算**：任务结束按小队状态给出三档评价——**★ 毫发无伤**（4 人无一倒地、几乎无伤撤离）/ **带伤突围**（撤出来了但有人带伤）/ **小队失联**（全员倒下），另附按用时 / 命中率 / 重试次数计算的战术评语（狼狈 → 手术刀级共六档）。

## 调试参数

通过 URL 查询参数控制调试行为：

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| `?shot=1` | `index.html?shot=1` | 进入截图/自动启动模式（强制 `test` 画质档） |
| `?cam=` | `?shot=1&cam=x,y,z,tx,ty,tz` | 指定相机位置与注视点（配合 `shot` 使用；`cam=` 空值清除） |
| `?q=` | `index.html?q=low` | 画质档位：`low` / `medium` / `high` / `ultra` / `test`（默认按设备自动选择） |

另支持 `?seed=`（随机种子）、`?bench=1`（基准测试，自动静音并自动开始）。控制台暴露 `window.__G`（游戏上下文）与 `window.__setShot(...)`（运行时切换相机 / FOV / 曝光）。
